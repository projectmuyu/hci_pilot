# 방 사진 풀 만들기

팀이 모은 방 사진 폴더를 검색 페이지용 풀로 바꾼다. 결과물은 두 개다.

- `room_pool.zip`: `pool.csv` + `photos/*.jpg`(긴 변 1600px). 검색 페이지 관리 화면의 "풀 불러오기"로 그대로 넣는다.
- `pool.csv`: 열은 `file, tags, contains`. tags는 `;`로 구분하고, contains는 사진에 보이는 타깃 요소(`식물;러그;스탠드 조명;벽 그림;겹친 침구·담요` 중)로, 타깃 요소 태그에서 자동으로 채워진다. 검색에서 빼는 용도가 아니라, 나중에 요소 포함 비율을 맞추기 위한 표시다.

## 준비

Pillow 11.3 이상이 필요하다(AVIF를 읽으려면). 없거나 낮으면 `pip install -U "pillow>=11.3"`(필요하면 `--break-system-packages`)로 설치한다. 받는 형식: jpg, jpeg, jfif, png, webp, avif.

## 순서

이 스킬 폴더 경로를 `SKILL_DIR`이라 부른다. 작업 폴더는 사용자가 따로 말하지 않으면 사진 폴더 옆에 `<사진폴더이름>_pool_work`로 만든다.

### 1. 확인용 시트 만들기

```bash
python "$SKILL_DIR/scripts/make_sheets.py" "<사진폴더>" "<작업폴더>"
```

사진을 6장씩 묶은 `sheets/sheet_NN.jpg`와 번호→파일명 표 `index.json`이 생긴다. 하위 폴더, `__MACOSX`, 숨김 파일은 알아서 건너뛴다. 같은 이름의 사진이 있으면 멈추니, 사용자에게 이름을 바꿔 달라고 한다.

### 2. 시트를 보고 태그 달기

`sheets/`의 시트를 Read 도구로 하나씩 열어 본다. 사진 왼쪽 위의 `#번호`가 `index.json`의 번호다. 시트 한 장을 볼 때마다 `tags.json`에 그 6장의 태그를 바로 적어 둔다(긴 작업이 끊겨도 이어 갈 수 있게).

```json
{
  "1": ["차분한", "미니멀", "화이트", "베이지", "밝은", "햇살", "우드", "책상", "블라인드", "저상형", "깔끔한", "식물"],
  "2": ["아늑한", "빈티지", "그린", "우드", "저녁", "패브릭", "체크", "소파", "스탠드", "따뜻한조명", "러그", "액자", "생활감"]
}
```

태그 규칙 (`$SKILL_DIR/vocab.json`의 13개 분류):

- 꼭 붙일 것: 분위기 1~2개, 스타일 1~2개, 색 1~2개, 빛·시간대 1개, 생활감 1개(깔끔한·생활감·맥시멀 중).
- 가구(`의자` 포함)는 뚜렷하게 보일 때만 단다. 작거나, 멀리 있거나, 가장자리에 조금만 걸린 가구는 달지 않는다.
- 보이면 붙일 것: 패턴, 침대, 조명, 소품·장식, 공간·전망, 반려동물. 사진당 대략 10~18개가 된다.
- 색은 방 전체의 인상을 정하는 것만 단다(`파스텔`은 더 붙일 수 있다). `화이트`는 벽만 희면 달지 않고, 침구나 가구 같은 큰 요소도 희고 더 강한 색이 없을 때만 단다. 많이 달면 "화이트 앤 우드" 같은 검색이 걸러지지 않는다(2026-11-03 T01 피드백으로 다시 태깅함).
- 소재·질감은 눈에 띄는 것만 단다. `우드`는 침대 프레임·가구·벽 패널처럼 나무가 눈에 띌 때만 달고, 바닥이나 작은 소품만 나무면 달지 않는다.
- `서재`는 책상 주변의 작업 공간이 방의 뚜렷한 한 부분일 때만 단다.
- `소파`는 둘 이상 앉을 수 있는 소파에만 단다. 1인 안락의자는 `의자`로 달고, 침대 벤치와 빈백은 소파가 아니다. `책상`·`테이블`·`책장`은 실제 그 가구로 쓰이는 것이 알아볼 수 있게 보일 때 단다(ALT2는 상위 4장만 보여 주므로 태그가 정확해야 한다).
- **타깃 요소 5가지는 작든 크든 보이면 반드시 태그로 단다**: `식물`(화분·꽃 포함, 꽃이면 `꽃`도 함께), `러그`(카펫 포함), `액자`(그림·포스터·패브릭 포스터, 벽이나 선반에 둔 것), `스탠드`(바닥·탁상 스탠드, 무드등), `담요`(침대 이불 위에 담요·스로우·베드러너를 한 겹 더 얹거나 접어 쌓아 둔 것. 소파에 걸친 담요, 쿠션만 있는 것은 아님). `따뜻한조명`(노란 간접 조명·전구색 불빛이 켜져 있음)은 타깃 요소가 아닌 일반 조명 태그다. `build_pool.py`가 이 태그로 CSV의 `contains` 칸(비율 조정용)을 자동으로 채운다.
- 방 종류(침실·원룸·작은방·거실 등)는 달지 않는다. 그런 검색어로 결과가 걸러지지 않게 하려는 것이다.
- `아늑한`은 확실히 아늑해 보이는 사진에만 붙인다(흔하면 검색어로 걸러지지 않는다).
- 침대: `바닥매트리스`(프레임 없이 바닥에 매트리스), `저상형`(낮은 프레임), `수납침대`(서랍 달린 침대), `헤드보드`(머리판이 눈에 띔). 해당하는 것만.
- 생활감: `깔끔한`(정돈, 쇼룸 같음), `생활감`(흐트러진 이불, 물건이 나와 있음), `맥시멀`(소품과 장식이 많음).
- 어휘에 없는 말이 꼭 필요하면 짧은 한국어 명사로 쓴다. 이런 태그는 한국어로만 검색된다.
- 사람이 검색창에 칠 법한 말 위주로 붙인다. 사진에 없는 것은 붙이지 않는다.

### 3. ZIP과 CSV 만들기

```bash
python "$SKILL_DIR/scripts/build_pool.py" "<사진폴더>" "<작업폴더>"
```

태그가 빠진 사진, 어휘 밖 태그, 타깃 요소별 사진 수(태그에서 자동 계산)를 출력해 준다. 태그가 빠진 사진이 있으면 2단계로 돌아가 채운 뒤 다시 실행한다.

### 4. 사용자에게 알리기

저장소의 기본 풀을 바꾸는 경우: 저장소 루트의 `pool/`을 비우고 ZIP을 그 안에 풀어 `pool/pool.csv`와 `pool/photos/`를 만든 뒤 커밋한다. GitHub Pages로 연 검색 페이지는 다음 시작 때 자동으로 새 풀에 맞춘다.

짧게 알린다: 사진 수, ZIP과 CSV 위치, 타깃 요소별 사진 수. 넣는 방법은 "검색 페이지 관리 화면 → 풀 불러오기 → room_pool.zip"이라고 한 줄로 덧붙인다. 이전 풀이 들어 있으면 "전체 삭제" 후 불러오라고 안내한다.

## 이어서 할 때

사진을 더 모았으면 같은 작업 폴더로 1단계부터 다시 돌린다. 번호가 바뀔 수 있으니, 기존 `tags.json`은 파일명 키로 바꿔 두거나(`index.json`으로 번호→파일명 변환) 새 사진만 태그한다. `build_pool.py`는 번호 키와 파일명 키를 모두 받는다.
